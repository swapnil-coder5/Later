Later runs a local open-weight model through Ollama. The model extracts obligations, grounds each one in an exact quote, and prepares drafts in a structured format. You review the result.

Get your local AI running

  1. Install Ollama from ollama.com.
  2. Run ollama pull qwen3:4b in your terminal.
  3. Keep Ollama running. Later detects installed models automatically.

Model downloads need internet. Once installed, generation works offline. Your notes and drafts persist in this browser’s local storage; other people using this browser profile may see them.

Open innovation that matters

Swap the model for your hardware, inspect the entire prompt and validation code, and run without a paid inference API. Local inference still uses your computer’s memory and electricity.

Honest boundaries

AI drafts can be wrong. Evidence links verify the quoted source exists, not that every generated claim is correct. Later never sends messages or modifies your calendar; exports are yours to review and import. Minute estimates describe preparation effort, not measured time savings.
